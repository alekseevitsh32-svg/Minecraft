# MyCraft

Минимальная играбельная песочница в стиле Minecraft, написанная на **Python + pygame-ce**.
Все текстуры генерируются кодом — в репозитории нет ни одного `.png`.
Сборка в `.exe` через **GitHub Actions**.

## ✨ Возможности

- 🧱 **3D-мир** из блоков (per-column raycaster, ~30–60 FPS)
- 🌍 **Процедурная генерация**: холмы, слои stone → dirt → grass, вода, песчаные пляжи
- 🌳 **Деревья** (ствол + крона)
- 🏃 **Физика**: гравитация, прыжки, плавание, коллизии
- ⛏️ **Ломание блоков** с прогрессом и дропом в инвентарь
- 🧱 **Установка блоков** ПКМ
- 🖐️ **Рука от первого лица** с анимацией ходьбы и замаха
- 🎒 **Инвентарь** на 36 слотов + **хотбар** на 9
- 🔨 **Крафт 2×2** и **верстак**
- 🪵 **Деревянные инструменты**: кирка, топор, лопата, меч (ускоряют ломание ×4)
- 💾 **Сохранение миров** в JSON (`saves/world1.json`, `world2.json`, ...) с zlib-сжатием блоков
- 🎨 **Все текстуры рисуются кодом** при первом запуске
- 🖥️ **Сборка exe** автоматически через GitHub Actions

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | движение |
| `Space` | прыжок / плыть вверх |
| Мышь | обзор |
| `ЛКМ` | ломать блок (держать) |
| `ПКМ` | поставить блок / открыть верстак |
| `1`–`9` | выбор слота хотбара |
| Колесо мыши | смена слота |
| `E` | инвентарь + крафт |
| `ESC` | сохранить и выйти в меню |
